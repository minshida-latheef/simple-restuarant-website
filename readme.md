\# 🍽️ The Savory Bistro - Fine Dining Landing Page



A beautifully designed, fully responsive, and highly interactive restaurant landing page starter template built using clean vanilla \*\*HTML5\*\*, \*\*CSS3\*\*, and modern \*\*JavaScript\*\*. 



\---



\## ✨ Features Implemented



\*   \*\*Responsive Architecture:\*\* Handcrafted layouts using Flexbox and CSS Grid that scale smoothly across mobile, tablet, and desktop viewports.

\*   \*\*Dynamic Menu Filtering:\*\* Zero-latency JavaScript filter buttons allowing customers to isolate Mains, Desserts, and Drinks instantly.

\*   \*\*Interactive Booking Engine:\*\* A smooth, fully functional Table Reservation Modal overlay with dynamic input constraints and native submission handling.

\*   \*\*Fluid Navigation:\*\* Smooth contextual page-scrolling configurations mapped to structural target hooks.



\---



\## 📂 Project Architecture



Organise your local runtime directory structure cleanly as mapped below:



```text

savory-bistro-website/

│

├── index.html     # Semantic page structure \& baseline document tags

├── style.css      # Design layouts, components, variables \& media queries

└── script.js      # Modal triggers, filters, form interceptors \& logic

```



\---



\## 🚀 Rapid Local Deployment



Follow these elementary steps to spin up the local development interface:



1\. \*\*Create Directory:\*\* Create a standard folder on your desktop computer machine named `savory-bistro-website`.

2\. \*\*Write Files:\*\* Create three raw empty files inside the folder exactly matching the filenames `index.html`, `style.css`, and `script.js`.

3\. \*\*Inject Code:\*\* Copy-paste the corresponding structural, presentation, and logic code segments provided in the project blueprints into each corresponding file.

4\. \*\*Boot Server:\*\* Double-click on `index.html` to instantly launch the localized frontend execution view inside any modern web browser wrapper context.

\## 🎨 Technology Architecture Configuration



\*   \*\*Structure:\*\* Vanilla HTML5 Semantic Elements (`<header>`, `<nav>`, `<section>`, `<footer>`).

\*   \*\*Styling Engine:\*\* Native CSS3 featuring standard structural Custom Variable Modules (`:root`), absolute layouts, and fluid Media Queries thresholds.

\*   \*\*Interactivity Scope:\*\* Vanilla ECMAScript (JavaScript Document Object Model interface event-loop architecture listeners).
